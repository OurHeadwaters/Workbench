## WHAT THIS SYSTEM IS

The Survival Podcast (TSP) has produced 3,000+ episodes over 15+ years. 
This project turns that archive into a structured discovery and progression 
engine — not a podcast website, but a guided self-reliance curriculum.

The engine runs on three artifacts:
- **Survival Podcast web app** — the main discovery engine (tsp.show/)
- **API Server** — ingests RSS feeds, stores episodes, serves all data
- **TSP Mobile** — Expo React Native app for on-the-go access

The web app is built in React + Vite. The API server uses Express + 
Drizzle ORM on Postgres. Auth is Replit Auth (OpenID Connect).

## DATABASE SCHEMA (key tables)

- **content_items** — All episodes (TSP + ULG), with title, summary, 
  categories (jsonb), tags (jsonb), audioUrl, episodeNumber, publishedAt
- **expert_council** — Experts with zones (jsonb) and podcastFeedUrl
- **ulg_businesses** — ULG businesses with zones (jsonb) and url
- **user_track_progress** — userId, trackSlug, episodeId, completedAt
- **wisdom_gems** — Extracted key quotes from episodes
- **content_gap_submissions** — Listener topic requests
- **wishing_well_tips** — Listener tips tied to a wishText and draw system
- **users / sessions** — Replit Auth tables

## THE BUSINESS OPPORTUNITY FRAMING

The engine owns the moment between **learning intent** and **purchase 
readiness**. A Zone 2 visitor arrives curious about food growing, gets 
matched to the "Growing Your Own" track or the "Conventional → Regenerative" 
transformation path, follows structured progression backed by expert voices 
(Marjory Wildcraft, Sam Nowak), and encounters vetted Zone 2 businesses 
(Flood & Fire Organics, Ames Farm, Mountain Rose Herbs) exactly when the 
content makes them relevant.

**Zone 2 primary demographic:**
- Suburban homeowner, 35–55, has a backyard and wants to use it
- Post-2020 food anxiety — started a garden, quit, wants a real system
- Aspiring homesteader not there yet — Zone 2 is as far as they can go now
- Parent/provider mindset — motivated by feeding family, not fear
- Existing TSP listener — trusts Jack, wants the archive organized for them

**The pitch:**
This is not advertising. It's curriculum-integrated commerce. The business 
appears at the lesson where it belongs. No banner. No sidebar. The listener 
is already in the right headspace when the product surfaces.
