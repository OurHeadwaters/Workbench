**Here’s the complete hardening plan with exact code changes.** All inbox routes become owner-token protected, the frontend continues to work, and Settings gains a live audit panel + revocation guidance.

### 1. Gate every inbox route with `requireOwner`

**File:** `artifacts/api-server/src/routes/inbox.ts`

Add the import at the top (with the other imports):

```ts
import { isOwnerRequest, OWNER_TOKEN } from "../lib/ownerAuth";
```

Then add this small helper (same shape used in `deadhead.ts` / `taskAutopilot.ts`) right after the imports / before the router:

```ts
function requireOwner(req: Request, res: Response): boolean {
  if (!isOwnerRequest(req)) {
    res.status(401).json({ error: "Unauthorized – owner token required" });
    return false;
  }
  return true;
}
```

Wrap **every** route handler. Example pattern (apply identically to all five):

```ts
// /api/inbox/threads
router.get("/threads", async (req, res) => {
  if (!requireOwner(req, res)) return;
  // … existing logic …
});

// /api/inbox/threads/all
router.get("/threads/all", async (req, res) => {
  if (!requireOwner(req, res)) return;
  // … existing logic …
});

// /api/inbox/accounts/status
router.get("/accounts/status", async (req, res) => {
  if (!requireOwner(req, res)) return;
  // … existing logic …
});

// /api/inbox/archive
router.post("/archive", async (req, res) => {   // or GET if that’s what it is
  if (!requireOwner(req, res)) return;
  // … existing logic …
});

// /api/inbox/thread/:id/body
router.get("/thread/:id/body", async (req, res) => {
  if (!requireOwner(req, res)) return;
  // … existing logic …
});
```

After this change, any call without the correct `Authorization: Bearer <OWNER_TOKEN>` (or whatever header `isOwnerRequest` checks) returns **401**.
