### Priority 2 — SEO and discoverability

**2a. Meta / Open Graph**
- The Stomping Path needs proper OG tags: title, description, image, URL
- OG image already exists at `artifacts/survival-podcast/public/opengraph.jpg`
- Description: *"A curated path through 6,000+ episodes of personal sovereignty. See the problems. Stomp the solutions."*
- Twitter card: `summary_large_image`

**2b. Structured data**
- Add JSON-LD on episode pages: `PodcastEpisode` schema
- Add JSON-LD on the homepage: `WebSite` + `Organization` schema
- Silent Mall Story: add `VideoObject` schema for the film

**2c. Sitemap**
- Generate `/sitemap.xml` from the API server
- Include: homepage, all episode slugs (`/library/:slug`), all track slugs (`/tracks/:slug`), all zone pages (`/zones/:id`), `/transform`, `/stomping-grounds`

### Priority 3 — Social seeding infrastructure

**3a. Social share cards**
- Each episode page needs a unique OG image (episode artwork + title + "The Stomping Path" branding)
- Each transformation path needs a shareable card: *"My transformation: [from] → [to] on The Stomping Path"*
- The Daily Stomp completion should show a share prompt: *"Day [N] on the path. [prompt answer redacted]. #StompingPath"*

**3b. Short-link / UTM wrapper**
- Create a simple redirect service or use a free short-link service
- UTMs for each traffic source: `?utm_source=film&utm_medium=cta`, `?utm_source=pitchdeck`, `?utm_source=twitter`, etc.
- Track these in the existing DB — add a `page_views` or `utm_events` table

### Priority 4 — Email capture and retention

**4a. Wire the "Stay on the Path" email form**
- Currently the form in `CommunitySection` on the homepage is UI-only (no backend)
- Add a `POST /api/subscribers` endpoint in the API server
- Store emails in a `subscribers` table (Postgres): `id`, `email`, `created_at`, `source` (UTM or referrer)
- Send a welcome email using a transactional email service (Resend is recommended — free tier, great DX)
- Welcome email copy: *"You're on the path. Here's where to start."* + link to the 3 most foundational tracks

**4b. Weekly digest**
- Every Monday, send a digest to subscribers: today's Daily Stomp prompt, one featured episode, one gear find
- Pull from existing `/api/episodes/featured` and gear shelf endpoints
- Schedule via a cron job in the API server (already has `startGearSchedule()` as a pattern)

### Priority 5 — Conversion optimization

**5a. Heatmap / basic analytics**
- Add Plausible Analytics (privacy-respecting, no cookies, no GDPR issues) — single script tag
- Track: pageviews, outbound clicks (film links, Amazon gear), stomp completions, track starts

**5b. First-visit experience**
- If a visitor arrives from `?utm_source=film` or `?utm_source=pitchdeck`, show a subtle welcome banner:
  *"You made it. You're on The Stomping Path now."* — dismissable, amber, top of page
- After 3 pageviews, prompt: *"Want a weekly nudge?"* — email capture modal

**5c. Path completion micro-moments**
- When a user completes their first track episode: show a small celebration + share prompt
- When streak hits 3 days: show *"3-day stomper"* badge + share prompt
- These fire confetti + update the vine progress

## Useful context for the agent

- Jack Spirko created The Survival Podcast. This is a fan redesign — not an official product. Frame all marketing accordingly ("a community fan experience" or "an unofficial companion").
- The Stomping Path's audience: people who are done with the grind, exploring Bitcoin/sovereignty, interested in permaculture/homesteading, libertarian-leaning, distrust corporate systems. They respond to earned authenticity, not marketing polish.
- "Stomp" is the verb. "Path" is the arc. "Grounds" is the homestead. Keep this metaphor consistent.
- Bitcoin-only means no Stripe, no PayPal, no Venmo. If monetization is added later, it goes through a Bitcoin Lightning wallet (BTCPay Server or Alby).
- The vine progress bar and daily stomp XP are deliberately gamified but never annoying — they reward action, not attention.
