7D Checklist & Prompt Set for Kitchen Table SessionsKeep it lightweight — one page, printable or in-app sidebar. Use it at the start of Sounding, Working, or Review modes. The Six Seats (plus configurable) run through it together.7D Kitchen Table Filter (North Star guided — run every proposal/decision through this)Physical/Material
Prompt: What tangible things (resources, bodies, land, tools) does this touch?
Check: Does it respect the physical headwaters and survival floor (Bucket 1)?
Gord Test version: “Can a northern person see the real cost on one page?”
Biological/Living Systems
Prompt: How does this affect health, ecology, vitality, or the living bond?
Check: Does it keep life flowing or drain the watershed?
Psychological/Narrative
Prompt: What stories or inner parts does this touch? Does it honor personal and shared narratives?
Check: Does it risk fragmentation or support integration? (Protect raw heart-to-heart.)
Quantum/Probabilistic
Prompt: What branching possibilities or uncertainties does this open or close?
Check: Are we comfortable with the range of futures this creates?
Soul/Spiritual
Prompt: Does this preserve essence, gifted qualities, or soul integrity?
Check: Any risk of extraction or forced naming of the sacred? (Default to protection.)
Collective/Inter-subjective
Prompt: How does this affect trust circles, mutual aid, and community multipliers?
Check: Does it build ownership or create new dependency?
Future/Timelines/Long View
Prompt: What does this leave seven generations from now? (Ishmael seat leads)
Check: Seven-Generation Scrutiny + Honey Principle + Eave Rule.

Quick Session Flow:Drop item on table → Quick 7D scan (5–10 min) → Seats deliberate → Seal or reroute.
End with: “Does this pass the Gord Test at this kitchen table?”
