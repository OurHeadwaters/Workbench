1. Worked examples (codetry — metaphor IS the architecture)
Saltbox / Zone 0

Lock-In Wins. 15 quiet minutes is enough to count. Ambient SVG ring, no MM:SS digits, no sound, no notification, no streak, no score. Saves to the keepsake as a Moment tagged lock-in. The timer is silent because "lock-in" is a state of attention, not a measured performance.
Gentle Words. 6-line bank. ≤1×/day per surface (Home + Wrap-Up gated independently), Deakon's voice ≤1×/week. Scarcity is the design — a line loses its weight when it's shouted daily.
Brave Moments. Amber Shield, one-tap capture from Home, surfaced per-child in the seasonal Family Recap (screen + printable). Courage is named, kept, and surfaced — never scored.
Quote of the Day. Deterministic per calendar date (same quote all day, rotates next morning). Parents add their own; the Parr trampoline quote is in the starter set. The quote rests with the day — not refreshed on every render.
Live Follow-Along. Opt-in only, passphrase as header (X-Share-Pass), lock-in count deliberately excluded from the share payload. Privacy is the default posture, not a setting.
Family Buckets / Zone 1

Bucket kinds. savings (target + cadence) and memory (entries + optional photo URL). Courage Bucket is the named memory preset. A bucket holds whatever you decide a bucket holds — the schema reflects that.
Allowance modes. manual / auto_planner / auto_xrpl. The XRPL path queues a pending payout; the parent still signs in-wallet. Automation never bypasses the signing hand — XRPL stays non-custodial.
Notifications. In-app inbox + opt-in email (Resend) + opt-in web-push (allowlisted browser endpoints, SSRF-guarded). Per-family channel preference, deep-link into the activity-page approval banner. The alert and the action live one tap apart.
Wallet handoff (v1). pay-xrpl returns txjson + a deep link; parent pastes the resulting hash to confirm. Real Xaman swap is a known follow-up (#165, #173). The seam is real even when the transport is mocked.
2. Naming-as-design — don't rename without a Zone 2 review
xBuckets / Headwaters (Zone 1 household budget) is the parent metaphor. Family Buckets is the kid-allowance + courage extension, not a rename.
Lock-In ≠ Focus Timer. Calling it a focus timer reintroduces measurement and would force the digits back.
Memory bucket ≠ gallery or album. Bucket keeps it inside the Zone 1 metaphor — drops you channel.
Moment (Saltbox keepsake) ≠ Note ≠ Entry. Three different objects in three different surfaces; collapsing them collapses the zones.
