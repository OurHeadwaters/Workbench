Payment Architecture
Stripe — all card payments. The pattern throughout the codebase:

artifacts/api-server/src/lib/kit-products.ts — auto-creates Stripe Products + Prices on startup for direct-purchase kits. Use KIT_STRIPE_PRICE_IDS env var (JSON) to skip API calls in prod.
artifacts/api-server/src/lib/brigade-products.ts — Brigade monthly ($9/mo) and annual ($97/yr). Controlled by BRIGADE_MONTHLY_PRICE_ID and BRIGADE_ANNUAL_PRICE_ID env vars.
artifacts/api-server/src/routes/stripe-workshops.ts — Stripe Connect for workshop hosts (split payments).
Webhook fires on successful payment → records purchase → sends delivery email → adds buyer to Kit.com email list. This fires even if browser closes before the thank-you page loads.
Each buyer gets a permanent session link (bookmarkable, device-recoverable via receipt email address).
Zaprite / Bitcoin — TSP-specific, Jack Spirko's channel. Rules:

Zaprite handles Bitcoin-only payments on TSP content
ZAPRITE_WEBHOOK_SECRET is not yet set — do not put real Bitcoin payments live until this is configured
XRPL wallets live in artifacts/codetry/ only — the Eave Rule forbids any DB join connecting a Zone 3 wallet address to a Zone 1 household record

Hard Rules — Do Not Cross
Eave Rule — No database join may ever connect a Zone 3 XRPL wallet address to a Zone 1 household record. If your feature touches both zones, stop and flag it.
Bitcoin on TSP = Zaprite only — No Lightning or XRPL on the Stomping Path. Codetry only.
ZAPRITE_WEBHOOK_SECRET must be set before real Bitcoin payments go live — it is currently not set.
Shopify is external — Green Salt and The Salty Onion redirect to parrsjars.ca. Do not build checkout for them here.
Headwaters is passphrase-gated — env var HEADWATERS_PASSPHRASE. Unguarded routes: /stomping-path/*, /shallows, /overview, /print, /guide. Everything else requires the passphrase.
API server is port 8080 — hard requirement, do not change.
Brand voice — warm, practitioner, northern Ontario. No "platform / onboarding / ecosystem / stakeholder / synergy / scalable". Five-line manifesto: START WHERE YOU ARE / USE WHAT YOU HAVE / DO WHAT YOU CAN / TRACK IT ALL / GROW, BABY, GROW
