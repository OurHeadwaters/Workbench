# Slide editors — read before adding spiritual or cultural content

The full rule lives at `docs/spiritual-imagery-rule.md` (repo root). The one-line version:

> **Imagery and the true stories that accompany it only — never invented words placed in anyone's mouth.**

Before you add or edit any slide copy that touches:

- Elders, Knowledge Keepers, or community members' voices,
- Ceremony, prayer, smudge, drum, sacred, ancestor, seven-generations language,
- Treaty references handled as voiced sentiment (vs. factual context),
- Anonymous quotes ("Heard in Deer Lake," "as the Elders say"),
- Composite or vox-pop community speech,

…stop, read `docs/spiritual-imagery-rule.md`, and either source + attribute the words or leave a visible placeholder:

```
Needs guidance from elders / wisdom keepers — placeholder, not for delivery.
```

Currently-flagged spots in this deck are tracked in `docs/spiritual-imagery-flags.md`. If you add or remove a flagged spot, update that file in the same commit.

The founder's own voice (attributed to the founder) is fine. Statistics from named sources are fine. Imagery on its own is fine. Invented voice attributed — even implicitly — to anyone else is not.
