# Deer Lake deck — read-aloud session worksheet

**For the founder to fill in during a live session with a band-council
member or the contractor.**

## How to run the session

1. Open the deck in the workspace preview alongside this worksheet.
2. Read each slide out loud, slide by slide, in deck order. Take turns
   with the reader if that helps.
3. After each slide, ask the reader directly:
   - "Did anything stumble when you said it?"
   - "Did anything land as confusing or business-y?"
   - "Is there a Deer Lake word for this we should be using?"
4. Write what they said in the **reader's reaction** column.
5. Pick **edit / gloss / leave** in the **decision** column.
6. The pre-flagged items in `read-aloud-audit.md` are the agent's
   guesses about what will trip the reader — ask the reader about each
   one explicitly. They're starting points, not the whole list.

When the session ends, the **decisions** column becomes the input for
the next code task: "apply these specific edits."

## After the session

1. Save this file (filled in) under the same name. The follow-up code
   task will read from the **decision** column to know what to change.
2. Cross-reference against `read-aloud-audit.md` — anything where the
   reader disagreed with the agent's pre-flag should be noted in the
   audit's row for that item, so the next code task knows the call.
3. If the reader flagged something the agent missed, add a row at the
   bottom of the relevant slide section with the new quoted phrase.
